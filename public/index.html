Conhecer o projeto

Por que criamos o ScoreInvest?

Consultar uma cotação é simples. Já comparar o histórico de várias ações e calcular os indicadores exige mais trabalho.

Nossa proposta é reunir essas informações em um painel, para que você possa consultar o histórico, comparar médias móveis e observar os cruzamentos sem fazer cada cálculo manualmente.

O foco do projeto

Organizar os dados para facilitar a análise.

O ScoreInvest trabalha com dados históricos. Os indicadores ajudam a interpretar esse histórico, mas não garantem o próximo movimento do mercado.

O que você encontra no painel

Preços, médias e cruzamentos reunidos para acompanhar os ativos.

Como os dados chegam até você

O cálculo acontece antes da consulta no painel.

1

Organizamos o histórico

Os registros de preços são tratados e organizados por ativo e data.

2

Calculamos as médias

A partir dos preços, calculamos os indicadores e identificamos os cruzamentos.

3

Você consulta no painel

Os resultados ficam reunidos para consultar e comparar os ativos analisados.
